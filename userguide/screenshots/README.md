# Guide screenshots

The following screenshots were captured from the running Alter v1.3.2 dashboard
on 27 September 2026 at 1600 × 900:

- `overview.png`: overview of four local sample services.
- `processes.png`: services grouped into commerce and workers namespaces.
- `process-detail.png`: the report worker's controls and live output.
- `start-page.png`: an illustrative worker configuration; the form was not submitted.
- `live-logs.png`: API output filtered to health requests, with Memory Insights expanded.
- `log-library.png`: saved API output in Log Library.
- `log-analytics.png`: stdout and stderr activity across sample services.

These are unaltered browser captures of a local demonstration workspace, not
production data. Other screenshots in this directory are existing project assets
retained for the corresponding guide sections.

The guide and repository README share these files. When replacing an image,
capture the real application, retain a descriptive filename, and update its
dimensions and alternative text in `userguide/index.html`.
